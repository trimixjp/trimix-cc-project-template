# DOD（Definition of Done）— ドキュメント作成・更新

> **対象**: 仕様書・マニュアル・ガイドライン・README等の作成・更新
> **Contributor がクローズ前にこのチェックリストで完了を判断します**

---

## ✅ 企画・方針

- [ ] Editor-in-Chief による方針決定コメントが存在する
  - ドキュメントの目的・対象読者・構成が明記されている
- [ ] 既存ドキュメントとの整合性が確認されている（重複・矛盾がない）

## ✅ 内容

- [ ] Writer による本文が完成している
- [ ] 対象読者が求める情報が網羅されている
- [ ] 手順・操作説明は実際に動作確認された内容になっている（または「未確認」と明記）
- [ ] スクリーンショット・コードサンプルがある場合は最新の状態を反映している
- [ ] 古い情報・廃止された情報が削除または更新されている

## ✅ コンプライアンス

- [ ] Compliance によるチェックが完了し「合格」コメントがある
- [ ] 法的・規約上の問題がある表現が含まれていない
- [ ] 機密情報・個人情報が含まれていない

## ✅ 品質

- [ ] 誤字・脱字の確認が完了している
- [ ] 見出し構造が論理的に整理されている
- [ ] 関連ドキュメントへのリンクが適切に設定されている

---

**完了判定**: 上記すべての項目が ✅ であることを Contributor が確認してから Issue をクローズします。
