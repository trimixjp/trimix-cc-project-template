# DOD（Definition of Done）— 新規コンポーネント作成

> **対象**: 新規 UI コンポーネントの作成・既存コンポーネントの大規模リファクタリング
> **Contributor がクローズ前にこのチェックリストで完了を判断します**

---

## ✅ コンポーネント設計

- [ ] 単一責務の原則に従っている（1コンポーネントが1つの機能を担う）
- [ ] Props のインターフェースが明確に定義されている（型定義・必須/任意の区別）
- [ ] 再利用可能な設計になっている（特定のページに依存しない汎用設計）
- [ ] Frontend-Lead の設計方針コメントが存在する

## ✅ 実装

- [ ] Frontend-Lead の設計方針に従い実装されている
- [ ] 変更ファイル一覧が Developer のコメントに列挙されている
- [ ] デザインシステム・スタイルガイドに準拠している
- [ ] プロジェクトのコーディング規約に従っている

## ✅ アクセシビリティ

- [ ] 適切な ARIA 属性が付与されている（role・aria-label・aria-describedby 等）
- [ ] キーボードナビゲーションが機能する（Tab・Enter・Escape 等）
- [ ] フォーカス管理が適切（フォーカストラップ・フォーカス復元）
- [ ] WCAG 2.1 AA 基準のコントラスト比を満たしている
- [ ] スクリーンリーダーで操作可能なことを確認している

## ✅ レスポンシブ・ブラウザ互換

- [ ] モバイル・タブレット・デスクトップで正常に表示される
- [ ] 対象ブラウザで動作確認済み

## ✅ パフォーマンス

- [ ] 不要な再レンダリングが発生しない設計になっている
- [ ] 画像・メディアが適切に最適化されている（コンポーネントが画像を扱う場合）

## ✅ テスト

- [ ] コンポーネントのユニットテストが実装されている
- [ ] 正常系（デフォルト表示・各 Props のパターン）のテストが網羅されている
- [ ] エラー状態・エッジケースのテストが含まれている
- [ ] アクセシビリティテスト（axe 等）が実装されている
- [ ] 既存テストがすべて通過している

## ✅ ドキュメント

- [ ] コンポーネントの使用例が記載されている（コードコメントまたは README）
- [ ] Storybook 等のコンポーネントカタログがある場合は Story が追加されている
- [ ] 全 Props の説明（型・用途・デフォルト値）が記載されている
- [ ] 使用上の注意点・制約事項が記載されている（あれば）

## ✅ コードレビュー

- [ ] Reviewer によるレビューが完了し「合格」判定がある
  - シングルレビューの場合: Reviewer コメントに「合格」あり
  - ダブルレビューの場合: Reviewer-A・Reviewer-B のクロスレビューで「合格」あり
- [ ] 指摘された CRITICAL / HIGH 件数が0件
- [ ] 差し戻しがあった場合、全件対応済みのコメントがある

## ✅ PR・マージ

- [ ] PR が作成されている
- [ ] PR 本文にコンポーネント設計方針・アクセシビリティ対応・テスト結果が含まれている
- [ ] PR にコンポーネントの表示スクリーンショットが添付されている
- [ ] 人間が PR を承認・マージ済み

---

**完了判定**: 上記すべての項目が ✅ であることを Contributor が確認してから チケットをクローズします。
