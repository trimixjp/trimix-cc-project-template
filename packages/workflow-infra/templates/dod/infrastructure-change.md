# DOD（Definition of Done）— インフラ構成変更

> **対象**: クラウドリソース・Terraform・Kubernetes・CI/CD等の変更
> **Contributor がクローズ前にこのチェックリストで完了を判断します**

---

## ✅ 設計・要件

- [ ] Infra-Lead による設計方針コメントが存在する
  - 変更内容・影響範囲・リスクが明記されている
  - 公式ドキュメントの参照元が明記されている（推測での設定変更禁止）
- [ ] 変更対象の分類がコメントに記録されている
  - ネットワーク系 / クラウド構成系 / 両方
- [ ] Architect への助言依頼の要否が Infra-Lead コメントに明記されている
  - 依頼した場合: Architect の助言コメントが存在する

## ✅ 実装

- [ ] Network-Engineer または Infra-Specialist（または両者）による実装が完了している
- [ ] 変更内容（設定ファイル・コード・コマンド）がコメントに記録されている
- [ ] IaC（Terraform等）で管理されている場合はコードが更新されている
- [ ] 手動変更が必要な場合は手順書がコメントに記録されている

## ✅ セキュリティレビュー

- [ ] Security-Engineer によるレビューが完了し「合格」判定がある
- [ ] ポートの最小公開・最小権限の原則が遵守されている
- [ ] 認証情報・シークレットが環境変数またはシークレットマネージャーで管理されている
- [ ] 不要な公開エンドポイントが存在しない

## ✅ 検証・動作確認

- [ ] ステージング環境での検証が完了している（または検証困難な理由が記録されている）
- [ ] 変更後の動作確認結果がコメントに記録されている
- [ ] ロールバック手順が明記されている

## ✅ ドキュメント

- [ ] インフラ構成図・設定ドキュメントが更新されている（なければ「対象外」）
- [ ] 次回の運用者が変更内容を理解できるコメントがある

---

**完了判定**: 上記すべての項目が ✅ であることを Contributor が確認してから チケットをクローズします。
