v0.22.0 の変更点

このページは、直前バージョン v0.21.1 から v0.22.0 までの変更点をまとめたものです。ソースコードのコミット履歴に基づいて記載しています。

概要

v0.22.0 の主眼は、npm 配布物に同梱するドキュメントディレクトリのリネーム（public/ → ai-team-manual/） と、それに伴う ルート入口 index の自動バージョン追従化 です。あわせて、バージョンアップ時にルート index がコミットから取り残されないよう、ドキュメント担当エージェント（Tech-Writer）の手順と完了条件（DOD）を補強しました。

public/ から ai-team-manual/ へのリネームは破壊的変更を含みます。移行手順はバージョン移行ガイドを参照してください。

破壊的変更

ドキュメント同梱ディレクトリを public/ から ai-team-manual/ にリネーム

npm 配布物に含めるドキュメントディレクトリ（package.json の files）を public/ から ai-team-manual/ に変更しました。あわせて bin/postinstall.js がドキュメントを展開する先も、導入先プロジェクトの public/ から ai-team-manual/ に変更しています。

public/ は、多くのプロジェクトでビルド出力ディレクトリやホスティングの公開ルートとして使われる一般的な名前です。本パッケージがこの名前でドキュメントを展開すると、導入先が自前で使っている public/ と衝突するおそれがありました。この衝突を避けるため、専用の ai-team-manual/ にリネームしました。
  • 公開ディレクトリ public/ を ai-team-manual/ に git mv でリネームし、Git 履歴を保持しました（純粋なリネーム）
  • .gitignore の否定パターンを !ai-team-manual/docs/ に更新し、ビルド生成物の Git 追跡を維持しました

導入先に旧 public/docs/（本パッケージが過去に展開したもの）が残っている場合の扱いを含む移行手順は、バージョン移行ガイドを参照してください。

改善

ルート ai-team-manual/index.html のバージョン追従化

これまで手動で管理していたルートのリダイレクト用 index（最新版ドキュメントへの入口）を、docs-src/build.js の生成対象に加えました。ビルド時に config.latest（最新バージョン）へ直接リダイレクトする形で再生成されるため、常に最新バージョンへ自動で追従します。

これにより、バージョンアップ時にルートの入口が旧バージョンを指したまま取り残される問題（ドリフト）を解消しました。あわせて docs-src/build.js では公開ルートを PUBLIC_ROOT として切り出し、PUBLIC_DOCS を DRY 化しています。

Tech-Writer のコミット手順と DOD を補強

バージョンアップ時にビルドで再生成されるルート ai-team-manual/index.html が、コミット対象から漏れて配布物のルート入口がドリフトする問題を防ぐため、Tech-Writer エージェントの手順を修正しました。

  • コミット時の git add 対象を ai-team-manual/docs/ から ai-team-manual/ に拡張し、ルート index も同一コミットに確実に含めるようにしました
  • 完了条件（DOD）に、ルート index を同一コミットへ含めるチェック項目を追加しました
  • 真のソース（SSOT）と配布複製の両系統に同じ修正を反映しました
