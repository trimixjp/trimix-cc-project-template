# AIチームのセットアップ

`ai-team setup` コマンドを実行すると、対話形式のウィザードが起動します。

## セットアップの流れ

### ステップ1: チームの選択

使用するチームを選択します。複数選択可能です。

```
? どのチームを有効にしますか？
❯ ◉ バックエンドチーム
  ◉ フロントエンドチーム
  ○ インフラチーム
  ○ コンテンツチーム
```

### ステップ2: GitHub 連携

GitHub リポジトリの情報を入力します。Issues のラベルが自動作成されます。

### ステップ3: 設定ファイルの生成

`.claude/` ディレクトリに以下が生成されます。

```
.claude/
├── teams/
│   └── backend/
│       ├── agents/       # エージェント定義
│       ├── dod/          # 完了定義テンプレート
│       ├── workflow.yml  # ワークフロー定義
│       └── review-config.yml
├── escalation-rules.yml
└── ai-team-config.yml
```

## ドキュメントディレクトリのセットアップ

バックエンドチームの Tech-Writer エージェントを使用する場合、以下のディレクトリも作成されます。

```
docs-src/          # ソースドキュメント（Markdownで執筆）
├── build.js       # ビルドスクリプト
├── config.json    # ドキュメント設定
└── versions/
    └── v1.0.0/   # バージョンごとのMarkdownファイル

public/docs/       # コンパイル済みHTML（ブラウザで閲覧可能）
```
