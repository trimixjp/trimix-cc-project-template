# エージェント定義リファレンス

エージェントは `.claude/teams/{チーム}/agents/{名前}.md` で定義します。

## ファイル構造

```markdown
---
name: エージェント名
description: 一行の説明（ワークフロー定義から参照される）
---

# エージェント名

## 役割
エージェントが何をするかを説明します。

## 起動条件
いつ、どのような条件で起動するかを定義します。

## 動作フロー
### ステップ1: ...
### ステップ2: ...

## GitHub Issueコメントフォーマット
エージェントが投稿するコメントのテンプレートを定義します。

## エスカレーション条件
人間にエスカレーションする条件を定義します。

## 重要な原則
エージェントが守るべき原則を定義します。
```

## 組み込みエージェント

### tech-lead

要件分析・設計方針決定・レビュー方式の自動判断を担います。

**起動ラベル:** `backend:tech-lead`

### implementer

Tech-Lead の設計方針に従いコードを実装します。

**起動ラベル:** `backend:implementer`

### tech-writer

コード変更差分を解析してドキュメントを更新し、HTMLにビルドします。

**起動ラベル:** `backend:tech-writer`

**動作:**
1. git diff でコード変更を解析
2. docs-src/ の Markdown を更新
3. `node docs-src/build.js` を実行
4. 変更をコミット
