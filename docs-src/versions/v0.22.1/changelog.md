# v0.22.1 の変更点

このページは、直前バージョン **v0.22.0** から **v0.22.1** までの変更点をまとめたものです。ソースコードのコミット履歴に基づいて記載しています。

---

## 概要

v0.22.1 の主眼は、**npm 配布物（tgz）に同梱するマニュアルを最新の 1 バージョンのみに絞り、パッケージを大幅に軽量化した**ことです。

これまでの配布物には、過去の全バージョン分のビルド済みマニュアルがそのまま同梱されており、パッケージが不必要に肥大化していました。バージョンを重ねるほど配布物が膨らみ、`npm install` のダウンロード量と展開時間が増え続けるという問題がありました。

v0.22.1 では、`docs-src/config.json` の `latest`（最新バージョン）を唯一の情報源として、配布時には最新バージョンのマニュアルだけを生成・同梱するように改めました。これにより、配布物のサイズを従来の約 14.9MB から約 2.8MB へ、およそ **81% 削減**しています。

なお、Git リポジトリ上では従来どおり全バージョンのマニュアルを保持しており、公開ドキュメントサイトではこれまでどおりバージョンを切り替えて閲覧できます。今回の変更が影響するのは npm 配布物と利用者環境への展開内容のみです。

---

## 改善

### 配布物に同梱するマニュアルを最新バージョンのみに限定

npm 配布物（`package.json` の `files`）に含めるマニュアルを、全バージョンから最新の 1 バージョンのみに変更しました。

- パッケージ公開直前（`prepack`）に配布専用のマニュアルツリーを生成し、公開後（`postpack`）に自動で削除するようにしました。配布ツリーは Git 管理の対象外です。
- 配布物には「最新バージョンのフルマニュアル」に加えて、「直前バージョンからの変更点（changelog）」も含まれます。利用者は最新の使い方と、前バージョンから何が変わったかの両方をオフラインで確認できます。

この結果、`npm install` 時のダウンロード量が減り、インストールと展開がこれまでより高速になります。

### 配布版でのバージョン切替 UI の非表示化

配布物には最新の 1 バージョンしか含まれないため、複数バージョンを前提としたバージョン切替 UI（version-switcher）を配布版では非表示にしました。利用者の手元に存在しないバージョンへの切替導線が表示されて混乱する、という状況を避けています。

公開ドキュメントサイト（全バージョンを収録）ではバージョン切替 UI はこれまでどおり表示されます。

### 利用者環境への展開も最新バージョンのみに

パッケージ導入時（`postinstall`）に利用者プロジェクトへマニュアルを展開する処理も、最新バージョンのみを展開するように変更しました。これにより、利用者側に展開されるファイルの肥大化も解消されます。

---

## 破壊的変更

なし。

コマンドの使い方や設定ファイルの形式に変更はありません。利用者側の操作で意識すべき非互換の変更はなく、配布物と展開内容が軽量化されるという改善のみです。
