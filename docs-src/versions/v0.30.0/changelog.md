# v0.30.0 の変更点

## 概要

v0.30.0 では、**エージェントが投稿するチケットコメントと PR 本文を、人向けの要点以外は折りたたむ書式** にしました。以前は全文が展開され、承認判断に必要な情報（コストの増減・既存環境への影響・人の対応の要否）が埋もれていました。今後のコメントと PR 本文は、要点だけが最初から表示されます。

## 主な変更

### コメントと PR 本文の折りたたみ（Issue #116）

**コメントの表示構成**

次の4つを表示したままにし、それ以外を `<details><summary>詳細（エージェント向けの記録）</summary>` に折りたたみます。

1. 1行目（`🔧 Tech-Lead: …`・`❌ Reviewer: 差し戻し（差し戻し回数: n/2）` など）
2. 人が知っておくべき要点1〜3行（判定結果・コストや既存環境への影響・訂正・人の対応の要否。人の対応が無いときは「人の対応は不要」）
3. 人への依頼の節（承認依頼・エスカレーションの判断依頼など）
4. `⏭️ 次のアクション:` 行

折りたたむのは表示だけで、必須 5 フィールドなどの記録の中身は削りません。

**1行目と `⏭️` 行を折りたたまない理由**

差し戻し回数の数え方（各コメントの1行目を照合）と `/ai-team-resume` の状態復元（最後の `⏭️ 次のアクション:` 行）が、コメントの生テキストからこれらを読むためです。そのため、この2つは必ず `<details>` の外に置きます。

**PR 本文**

`## 概要` と `## 承認前に知っておくこと` を表示し、残りは話題ごとの `<details>` に入れます。テスト欄（`**検証**:` 行と `## テスト`）は、実行したコマンドと結果だけを書く形になりました。CI・リントが無いときは「無し」と書き、代わりに行った確認を書きます。以前の雛形にあった「全件パス」「リント: エラーなし」のような既定の文言と、チェックリストの「CI がパスしている」は無くなりました。

**カスタムエージェントを書く方へ**

エージェント定義の完了報告の雛形は、この構成で書きます（雛形の書き方は [エージェントのカスタマイズ](guide/agents.html) の「コメントの表示構成」を参照）。`ai-team-create` が使うベーステンプレートと、プロジェクト内のエージェント記述ガイド（`.claude/docs/agent-writing-guide.md`）も、この構成に合わせて更新されています。

**`ticket_backend: local`（Obsidian）での見え方**

書式は `ticket_backend: github` と同じままです。Obsidian の公式ヘルプでは、HTML 要素の中の Markdown は描画されないとされているため、`<details>` は畳まれず全文が表示される見込みです（記録は失われません）。**実機では確かめていません**。Obsidian 向けの変換は、実機で見え方を確かめてから別に判断します。

**対象**

`skills/ai-team-run.md` に規約を追加し、共通エージェント 3 つ（`contributor`・`dispatcher`・`human-escalator`）と、backend・frontend・infra・content・youtube・sns の各チームのエージェント定義の雛形を、この構成に書き換えました。サブエージェントへ委託するときのプロンプトにも、この構成に従う条項を加えています。

## 既存環境への影響

**破壊的変更はありません**。`upgrade` でエージェント定義の雛形が更新されます。手編集したファイルは上書きされず、最新の雛形が `.new` として書き出されます。導入済みのチームによって、更新されるファイルの数は変わります。詳しくは [移行ガイド](guide/migration.html) を参照してください。
