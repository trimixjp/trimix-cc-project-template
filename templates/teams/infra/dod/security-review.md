# DOD（Definition of Done）— セキュリティレビュー

> **対象**: セキュリティ監査・脆弱性対応・権限設計レビュー等
> **Contributor がクローズ前にこのチェックリストで完了を判断します**

---

## ✅ レビュー準備

- [ ] レビュー対象のスコープ（システム・コンポーネント・対象ファイル）が Issue に明記されている
- [ ] レビュー目的（定期監査 / 脆弱性対応 / 新機能の権限設計等）が明記されている
- [ ] Infra-Lead による方針コメントが存在する

## ✅ セキュリティレビュー実施

- [ ] Security-Engineer によるレビューが完了している
- [ ] 以下の観点でレビューが実施されている
  - [ ] 認証・認可（IAM・ロール・権限設定）
  - [ ] 暗号化（転送中・保存時）
  - [ ] ネットワーク公開範囲（ポート・エンドポイント）
  - [ ] シークレット管理（ハードコードがないか）
  - [ ] ログ・監査証跡の設定

## ✅ 発見事項の対応

- [ ] 重大度（CRITICAL / HIGH / MEDIUM / LOW）別に発見事項が整理されている
- [ ] CRITICAL 件数: 0件（または対応済みで Security-Engineer の再確認「合格」あり）
- [ ] HIGH 件数: 0件（または対応済みコメントあり）
- [ ] 対応不要と判断した場合は理由がコメントに記録されている
- [ ] 中長期的な対応が必要な場合は別 Issue が作成されている

## ✅ 成果物

- [ ] セキュリティレビュー結果サマリーがコメントに記録されている
  - 発見件数（重大度別）・対応件数・全体評価
- [ ] 次回レビュー推奨時期がコメントに明記されている（なければ「対象外」）

---

**完了判定**: 上記すべての項目が ✅ であることを Contributor が確認してから Issue をクローズします。
